# Home Assistant Add-On repository (by Almidar)

## Home Assistant Addon repository containing

### <img src="cups/icon.png" width="40px"> CUPS ([cups.org](http://www.cups.org))

## Installation

[![Add repository on my Home Assistant][repository-badge]][repository-url]

If you want to do add the repository manually, please follow the procedure highlighted in the [Home Assistant website](https://home-assistant.io/hassio/installing_third_party_addons). Use the following URL to add this repository: `https://github.com/almidar/homeassistant-addons/`
